# 地表观感微调（Phase 13）

根据实际游戏观察调整两个视觉参数。

## 13.1 减少裸露石山

`ExtremeHillsBiome` 的石头山顶阈值从 `1.0` 提高到 `2.5`。

- 之前：极端丘陵中约 8% 的陆地表面是裸石。
- 现在：同一测试区域约 3.9% 的陆地表面是裸石。
- 保留高山顶部石质效果，但不再频繁出现大片石山。

## 13.2 增加草覆盖

提高常见群系的 `grassPerChunk`：

| 群系 | 旧值 | 新值 |
|---|---:|---:|
| 平原 / 向日葵平原 | 10 | 16 |
| 森林 / 森林丘陵 | 2 | 4 |
| 白桦林 / 白桦林丘陵 | 2 | 4 |
| 黑森林 | 2 | 4 |
| 针叶林 / 针叶林丘陵 | 1 | 2 |
| 冷针叶林 | 1 | 2 |
| 沼泽 | 5 | 8 |
| 丛林 / 丛林丘陵 | 25 | 30 |
| 丛林边缘 | 3 | 5 |
| Mega Taiga | 7 | 10 |
| 热带草原 / 高原 | 20 | 26 |
| 极端丘陵 | 0 | 3 |

验证：

- seed 16 平原：高草从 `31=32` 增加到 `31=55`。
- seed 11 森林：`31=8`。
- seed 7 沼泽：`31=9`。
- seed 19 Mega Taiga：`31=9`。

花、树、甘蔗等其它装饰未整体放大，避免再次出现“遍地花草”的观感。
