2026/7/3 #001 bugs:
!001 【已修复】
- 根因：Creature::onUpdate 摩擦公式中 (int)floor(z)-1 比正确坐标偏了一格，
  导致站在半砖/雪等非整格方块上时读到错误的方块摩擦系数
- 修复：floor(z)-1 → floor(z)
- 附加：击退 base 0.4→0.6 也增强了低方块上的击退距离

!002 【已修复】
- 根因：Zombie::$height = 0，导致 bounding box 高度为 0，
  碰撞检测 getCollisionCubes() 完全不检查上半身方块，直接穿墙
- 修复：Zombie::$height = 0 → 1.8
- 连带修复：Cow(0→1.3)、Chicken(0→0.7)、Wolf(注释掉→0.8) 相同问题

!003 【已修复】
- 根因：同 #002，height=0 导致 bounding box 无效，
  move() 中的碰撞检测不生效，击退 motion 直接穿过方块
- 修复：同上，height 改为正常值后 bounding box 恢复碰撞

2026/7/3 #002 bugs:
!001 【已修复】
- 根因：SnowLayer(雪片) 继承 Flowable，getBoundingBox() 返回 null，
  生物无碰撞箱可站立，直接穿透雪层落到下方地面
- 修复：SnowLayer::getBoundingBox() 返回基于层数的碰撞箱 height=(meta+1)/8
  hasEntityCollision() → true
- 附加：AIHolder::whatBlock 雪分类从 "air" 改为 "block",
  刷怪系统正确识别雪地为可生成地面

2026/7/3 #003 bugs:
!001 【已修复】
- 根因：修复 height 后 onGround 正常触发，但 Creature::onUpdate 中
  motionY *= -0.5 反弹逻辑将着陆后残留 motionY（~ -0.01）弹为正数，
  下一 tick 重力再拉负，形成反复上下震荡，生物无法正常移动
- 修复：onGround 时若 |motionY| < 0.01 则 motionY = 0 直接归零，
  不触发反弹，仅在大幅坠落时（motionY 显著为负）才执行 * -0.5 减震
